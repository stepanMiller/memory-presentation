# Память. Понять, что меняется

Внутренний просмотр для согласования, [черновой PR №3](https://github.com/stepanMiller/memory-presentation/pull/3).

Одна история из шести глав. В начале мужчина вспоминает о встрече и уточняет время. Тот же пример проходит через внимание, сохранение деталей и воспроизведение. От работы клеток история переходит к кровоснабжению, возможным изменениям мелких сосудов и проведению сигнала по волокну. В конце возвращается тот же человек.

[Принятая анатомическая версия](https://stepanmiller.github.io/memory-presentation/review/mechanisms/) служит основой. Все семь WebP берутся из тех же файлов репозитория. Для начала и финала используется собирательный портрет `v2/assets/man-50.webp` из [визуальных материалов V2](../v2/docs/VISUAL_PROVENANCE.md). Из фильма взята последовательность глав. Кадры фильма и раскадровки в сборку не входят.

```sh
npm run build:scroll
npm run preview:scroll
```

Сборка создаёт автономный `output/Memory-Scroll-Review.html`. Его можно открыть напрямую в браузере или через [локальный сервер](http://127.0.0.1:4175/). Для просмотра по локальной сети адрес прослушивания можно задать через `MEMORY_SCROLL_HOST`. Доступ с телефона зависит от сетевой доступности компьютера. Сборка не подключена к публикации GitHub Pages.

## Взаимодействие

Положение прокрутки определяет кадр, подпись и пояснение во всех 17 состояниях. При остановке прокрутки анимация замирает. При движении назад восстанавливаются положение камеры, отметки и текст. Режим уменьшенного движения показывает все состояния в виде статичных кадров в естественном порядке чтения. Развёрнутые пояснения и источники доступны в конце страницы.

## Медицинское согласование

Капилляр и артериола подписаны как отдельные учебные модели. Кислород обозначен светлыми точками. Сравнение показывает открытый и суженный просвет в одном ракурсе. Затем условно выделяются соседние волокна. На согласовании — ясность этого перехода, фраза о замедлении мышления и связь учебного изображения повреждённого миелина с подтверждённым дефицитом B12.

Опыт приёма Акатинола Мемантина упоминается как субъективное наблюдение для разговора с врачом. Упоминание торгового названия и медицинские формулировки подлежат согласованию Юлией Олеговной до выпуска.

## QA

После запуска предпросмотра выполнить `node scroll-review/qa.cjs` с Playwright, Chrome и WebKit. Переменная `MEMORY_PLAYWRIGHT` позволяет указать путь к установленному Playwright. Скриншоты и JSON-отчёт появятся в `output/scroll-qa/`.

Проверка включает семь ширин, прямой и обратный ход, совпадение текста и изображения в каждой сцене, синхронизацию подписи при смене образцов, автономный HTML и reduced motion. Эмуляция жестов в Chrome и Playwright WebKit на Windows дополняют ручную проверку, которую предстоит провести в Safari на физическом iPhone.
