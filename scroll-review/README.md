# Память. Понять, что меняется

Внутренний просмотр с управлением прокруткой. [Визуальная основа](https://stepanmiller.github.io/memory-presentation/review/mechanisms/) взята из редакции `6eea0d6`. Семь WebP загружаются из тех же исходных файлов при сборке. Используются исходные координаты и траектории поясняющих меток. Отдельные учебные масштабы и изменённые образцы имеют собственные подписи.

```sh
npm run build:scroll
npm run preview:scroll
```

Сборка создаёт автономный `output/Memory-Scroll-Review.html`. Его можно открыть напрямую в настольном браузере или через [локальный сервер](http://127.0.0.1:4175/). Для просмотра по локальной сети адрес прослушивания можно задать через `MEMORY_SCROLL_HOST`. Доступ с телефона зависит от сетевой доступности компьютера. Сборка не подключена к публикации GitHub Pages.

## Взаимодействие

Три закреплённых кадра и 12 последовательных состояний. Локальный прогресс прокрутки непосредственно определяет кадр. При паузе прокрутки анимация останавливается. На обратном ходе восстанавливаются положение камеры, отметки и текст. При уменьшенном движении все 12 статичных состояний остаются в естественном порядке чтения. Подробности и исходные ссылки вынесены в раскрывающийся раздел.

## QA

После запуска предпросмотра выполнить `node scroll-review/qa.cjs` с Playwright, Chrome и WebKit. Переменная `MEMORY_PLAYWRIGHT` позволяет указать путь к установленному Playwright. Скриншоты и JSON-отчёт появятся в `output/scroll-qa/`. Эмуляция iPhone и Playwright WebKit на Windows требуют финальной ручной проверки в Safari на физическом iPhone.

Медицинский выпуск ожидает согласования Юлией Олеговной.
