# MEMORY: контрольный эпизод «Из крови в ткань»

Отдельный вариант для художественного и медицинского согласования. Основа ветки: `8be58b9948ddf31f01fe6483e9f100d18d8dce03`.

[Открыть в браузере](https://raw.githack.com/stepanMiller/memory-presentation/review-oxygen-20261113/review/oxygen-control/index.html)

При первом открытии githack может показать служебную страницу: кнопка **Open the page** открывает эпизод.

## Состав

Один эпизод, три последовательных состояния, 24 секунды. Используется существующее изображение `../vascular/assets/microvascular.webp`. Новых изображений и стороннего движка нет. Пауза и стрелки позволяют остановиться и вернуться к состоянию; в конце автоматическое движение прекращается. При уменьшении движения используются статические состояния.

## Статус

Это учебная модель, не результаты обследования пациента. Светлые метки условно обозначают кислород, не молекулярную симуляцию. Окончательные медицинские формулировки и анатомическая точность подлежат согласованию с Юлией Олеговной.

Основная ветка, текущая история `review/cinematic-mobile/` и настройки GitHub Pages не изменяются. Разработка продолжается в этой ветке; слияние и замена основной публикации требуют отдельного согласования.
