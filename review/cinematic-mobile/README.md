# Cinema Mobile: контрольная версия без публикации

Черновой режим 17 коротких кадров, объединённых одной визуальной системой. Основа: ветка feature/memory-scroll-story и утверждённые изображения Living Anatomy.

- Заголовок и одно пояснение интегрированы в анатомическую сцену; нет отдельного текстового блока под изображением.
- На мобильном каждый вертикальный свайп переключает один смысловой кадр; пролистывание не зависит от таймера, ручных кнопок нет.
- Внутри кадра есть мягкое приближение, подсветки и условные маршруты в режиме анимации. Критический смысл остаётся в тексте и изображении.
- Для prefers-reduced-motion предусмотрен статичный режим.
- Мобильный прототип проверен в Chromium на 320/375/390/430 px и на десктопе; на физическом Safari ещё не проверялся.
- Не следует выдавать условное движение светлых точек за точную анатомическую траекторию. Все сцены требуют медицинского согласования.

Путь для предпросмотра из ветки: review/cinematic-mobile/index.html. Репозиторий публичный, но рабочая ветка не объединена с main и GitHub Pages не обновлялся.
