# Память. Понять, что меняется

Интерактивная HTML-история из восьми частей. Редакция для согласования 1.0, 13 ноября 2026. Публичной публикации нет. Медицинское согласование не завершено.

Основа: утверждённый Memory_Control_01 v0.2. Исходник сохранён без изменений в `baseline/control-v0.2/`. Изображения мозга и артерии используются из этой версии без перерисовки. Логотип VERBA и персональные сведения отсутствуют.

## Просмотр

Закрытая веб-версия для владельца: https://memory-understand-review.spartak19876.chatgpt.site. Требуется вход в тот же аккаунт ChatGPT. Публичный доступ выключен.

Откройте `output/Memory_Presentation_Review.html` в браузере. В файл включены все изображения, стили и код. Интернет не нужен. На iPhone системный просмотрщик вложений может не выполнять JavaScript: для полноценной проверки нужен Safari с локальным HTTP-сервером или закрытый веб-предпросмотр.

Для локального сервера требуется Node.js 22 или новее:

```sh
npm run build
npm run check
npm run preview
```

Адрес: `http://127.0.0.1:4173`. Сервер слушает только локальный интерфейс. Публичной публикации эта команда не выполняет. В управляемой среде доступен штатный `sites-preview start /absolute/project/path`.

## Управление

Вертикальная прокрутка свободная. В каждой сцене есть этапы, показ по шагам, пауза и возврат к началу. Содержание открывает любую часть. Автопросмотр всей истории длится около 4 минут 28 секунд. Ручная прокрутка ставит его на паузу. На маленьком экране автопросмотр переводит внимание от заголовка к анатомии и пояснению.

Переключатель «Движение» включает статичный режим; системное `prefers-reduced-motion` учитывается при запуске. В статичном режиме этапы доступны без анимации, кнопка показа становится переходом к следующему этапу. При отключённом JavaScript все объяснения доступны обычным текстом.

## Структура

| Путь | Назначение |
| --- | --- |
| `src/story.mjs` | Согласованная структура, тексты, этапы, источники |
| `src/styles.css` | Visual DNA и отдельная мобильная композиция |
| `src/app.js`, `src/motion.mjs` | Управление, анимации и переход масштаба |
| `src/assets/` | Четыре локальных изображения WebP |

| `dist/` | Готовые HTML/CSS/JavaScript и изображения для статического хостинга |
| `output/` | Самодостаточный HTML для закрытого просмотра |
| `tests/` | Проверки логики, компоновки и браузерного управления |
| `docs/` | Медицинское согласование, визуальная система, QA и развёртывание |
| `.github/workflows/check.yml` | Автоматическая проверка и сборка, без публикации |
| `deploy/yandex-deploy.yml.disabled` | Неактивный шаблон будущей публикации |

`src/index.html` генерируется из `story.mjs`. Вносите текстовые правки в данные истории, затем выполняйте сборку. `dist` и `output` не являются исходниками и исключены из Git.

## Проверки

`npm run check` проверяет синтаксис, структуру, внутренние ссылки, автономность HTML, неизменность утверждённых изображений, бюджет изображений и логику переходов.

Для полного браузерного прогона установите `playwright@1.62.1`, выполните `npx playwright install chromium`, запустите локальный сервер и `npm run test:browser`. CI выполняет это автоматически после помещения проекта в приватный GitHub-репозиторий. Текущий фактически выполненный объём проверки указан в `docs/QA.md`.

Встроенный локальный стенд: `node scripts/prepare-qa.mjs`, затем `/review.html`. Он проверяет девять размеров iframe в настоящем Chromium. Это проверка CSS-компоновки, не эмуляция аппаратного iPhone. Обычная сборка удаляет стенд из `dist`.
