# Память. Понять, что меняется

Три интерактивные анатомические демонстрации V2 для визуального и медицинского согласования: память, сосуды и B12.

Прямой просмотр: https://stepanmiller.github.io/memory-presentation/

Архив полной восьмиэкранной редакции 1.0: https://stepanmiller.github.io/memory-presentation/v1/

Доступ открытый, без входа в ChatGPT. Медицинское согласование пока не завершено.

## Исходники

- `v2/`: новая редакция, три контрольных механизма с ручным управлением.
- `src/`: сохранённая редакция 1.0.
- `baseline/control-v0.2/`: исходный контрольный экран.
- `v2/docs/`: медицинский лист согласования, происхождение визуальных материалов и результаты проверки.

Рабочая ветка V2: `v2/anatomy-mechanisms`. Архивная ветка V1: `archive/v1.0`. Публикация выполняется из `main` через GitHub Actions.

## Сборка

Node.js 22 или новее. Внешние зависимости для сборки не требуются.

```sh
npm run build:pages
npm run preview
```

`build:pages` проверяет обе редакции и создаёт `dist/`: V2 в корне и V1 в `v1/`. Сборка GitHub Pages не содержит QA-стендов, исходных документов, секретов или данных пациента.

Для отдельной V2: `npm run check:v2` и `npm run build:v2`.
Для сохранённой V1: `npm run build` и `npm run check`.

V2 прошла 107 браузерных проверок, включая девять ширин экрана. Аппаратный WebGL и Safari на физическом iPhone ещё требуют проверки; подробности в `v2/docs/QA.md`.

Все изображения, JavaScript и модели поставляются локально. Ничего не отправляется пациентам автоматически. Yandex Cloud не подключён. Репозитории VERBA Heart не изменяются.
