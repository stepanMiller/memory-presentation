# Память. Понять, что меняется: V2

Три работающие контрольные демонстрации для визуального и медицинского согласования. Это следующий этап разработки, не утверждённая восьмиэкранная презентация.

Рабочая ветка: `v2/anatomy-mechanisms`.

V1 сохранена в `main` и в неизменённых `src/`, `baseline/`, старых сборочных скриптах. Локальная точка V1: `a3ae0c858b7abfdc2e43935ec8dc17e7aa9c078b`. Публичный GitHub main на начало V2: `1de60eb2c968840524c4570651cb33025da56cfa`. Истории локального и GitHub репозиториев различаются, поскольку первоначальная выгрузка выполнялась через API; файлы V1 были синхронизированы.

## Запуск

```sh
npm run check:v2
npm run build:v2
npm run preview
```

Модули и анатомическая модель поставляются вместе с проектом. Во время просмотра внешние библиотеки и шрифты не загружаются. HTML открывается через HTTP, не через file://.

Для локальной браузерной проверки после сборки: `npm run qa:v2`, затем `__qa.html`. Финальная сборка не содержит QA-страницу.

Все процессы локальные, конечные и запускаются нажатием. Никакой таймер не переключает тему или этап. При скрытии страницы и смене сцены анимации останавливаются. Учитывается prefers-reduced-motion. Вертикальный жест сохранён через touch-action: pan-y; захват выполняется только после явно горизонтального движения.

## Анатомия и ограничения

Настоящая геометрия кортикальной поверхности fsaverage5: 10242 вершины на полушарие, 40960 треугольников суммарно. Это усреднённая поверхность полушарий, без полного набора подкорковых структур и мозжечка. Цветные пути, сосуды и внутренний элемент памяти являются схемами. Их нельзя читать как индивидуальные или точные функциональные карты.

Основной 3D-рендерер: WebGL2 / Three.js. Если WebGL отключён, используется упрощённый программный рендерер той же геометрии с перспективой и сортировкой глубины. Он сохраняет настоящий поворот, но уступает основному в плавности и освещении. Если недоступны оба режима, есть явно подписанная плоская схема. Размер буфера ограничен, постоянного цикла отрисовки в покое нет.

Реалистичные тканевые иллюстрации отдельно подписаны как иллюстрации. Их увеличение не называется 3D. Они созданы на основе исходных Memory Control и анатомических материалов VERBA Heart, затем подготовлены согласованные состояния для сравнения.
