# Память. Понять, что меняется

Контрольный HTML-экран 01, версия 0.2, 13 ноября 2026.

Одна сцена: «Как сосуды поддерживают работу памяти». Три состояния внутри сцены: мозг, сосудистая сеть, артерия в разрезе. Полная презентация не собрана. Материал не опубликован.

## Открытие

`Memory_Control_01.html` самодостаточен: HTML, стили, JavaScript и изображения внутри одного файла. Откройте в браузере. Интернет для работы экрана не нужен. Приложение «Файлы» на iPhone может показывать только Quick Look, который не исполняет JavaScript. Для проверки интерактива нужен полноценный браузерный просмотр HTML; после согласования будет ссылка на опубликованную веб-версию.

Кнопка «Смотреть переход» запускает последовательность примерно на 15 секунд. «Пауза» останавливает её. Состояния доступны отдельно через «Мозг», «Сосуды», «Внутри сосуда». В области иллюстрации можно перелистывать горизонтальным жестом. Кнопка «Без движения» и системное `prefers-reduced-motion` отключают переходы. При выключенном JavaScript остаются общий вид и основное объяснение.

## Исходники и сборка

`src/index.html`, `src/styles.css`, `src/app.js`, `src/assets/`.

Node.js 22 или новее. Внешние зависимости не требуются:

```sh
npm run check
npm run build
```

`dist/` содержит обычную статическую сборку для GitHub и Yandex Object Storage. `build.mjs` также выпускает автономный HTML. Включён только запускаемый вручную workflow сборки GitHub Actions. Деплоя, ключей, корзины хранения и автоматической публикации нет. Подключение Yandex Cloud отложено до отдельного согласования.

## Что изменено в версии 0.2

1. Анатомия, подписи, навигация и нижняя служебная строка размещены в отдельных строках CSS Grid. Подписи больше не привязаны к нижнему краю картинки абсолютным позиционированием.
2. Перед моделью артерии показана выбранная область мозга. Увеличение останавливается; исходная иллюстрация уходит, затем появляется отдельная модель. В углу сохраняется миниатюра мозга с той же отметкой. Подпись постоянно уточняет: «Учебная модель, не точный разрез выбранного сосуда. Масштаб условный». При прямом переходе из общего вида в модель есть остановка на сосудистой сети.
3. На телефоне сохранён естественный вертикальный поток. Подписи и кнопки могут переноситься. Основной текст от 15 px, активные элементы от 44 px по высоте. Вертикальные жесты и увеличение двумя пальцами не переключают сцену. Анатомические изображения и палитра сохранены без изменений.

## Статус проверки

Пользователь проверил исходную версию 0.1 в Chromium на десктопе и мобильных разрешениях и принял визуальное направление. Это не считается проверкой текущей версии 0.2.

Для версии 0.2 пройдены синтаксическая проверка и 11 проверок логики: смена состояний, разделение анатомических изображений, сохранение миниатюры, остановка на выбранной области, запуск/пауза/продолжение, reduced motion, клавиатура, жесты, остановка в скрытой вкладке. Проверены комплектность автономного файла и неизменность изображений.

Повторный браузерный прогон версии 0.2 в этой среде не завершён: локальный Chromium останавливается при создании системного сокета с ошибкой `Operation not permitted`. Попытка открыть HTML через графический рабочий стол также остановилась из-за отсутствия активного окна для ввода. Скриншоты текущей страницы не заявлены и не подменены макетами. `qa/check.cjs` подготовлен для проверки 27 сочетаний размера и состояния (ширины 320, 375, 390, 430, 768, 1024, 1280, 1440 и 1920 px), границ блоков, прокрутки, кнопок и анимации. Запуск: `NODE_PATH=<путь к модулям Playwright> node qa/check.cjs`. Реальный iPhone отдельно не проверен.
