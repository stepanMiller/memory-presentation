## Найдено и исправлено

На ширине 768 px длинные слова в заголовках сосудистой сцены и B12 выходили за свою колонку. Для этого диапазона скорректирован размер шрифта. При переходах устранено двойное сложение отступа под верхнюю панель. Закрытие содержания сразу возвращает обычную прокрутку.

## Границы проверки

Это Chromium и CSS-viewport проверка в iframe, не настоящий iPhone и не эмуляция WebKit. Аппаратные особенности Safari, VoiceOver, системное масштабирование текста и энергопотребление на устройстве ещё не проверены. Перед передачей пациенту нужен просмотр на реальном iPhone.

Первичная проверка выполнена в облачном Chromium через локальный стенд. Затем `npm run test:browser` реально выполнен отдельным процессом Playwright в GitHub Actions, все проверки прошли. Локальный контейнерный запуск ранее был заблокирован средой при создании сокета.

Продолжительность автопросмотра проверена по шкалам времени; завершение всех 268 секунд непрерывно не включено в перечисленные десять сценариев. Медицинская корректность иллюстраций требует врачебного согласования и не подтверждается тестами интерфейса.
